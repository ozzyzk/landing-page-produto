# 📖 Sobre o projeto

Esta Landing Page foi criada utilizando apenas tecnologias nativas da Web (HTML, CSS e JavaScript), demonstrando conhecimentos em desenvolvimento Front-end sem utilização de frameworks.

O projeto possui layout moderno, responsivo e animações suaves, podendo ser utilizado como base para páginas de produtos, empresas, serviços ou portfólios.

---

# ✨ Funcionalidades

- ✅ Layout totalmente responsivo
- ✅ Design moderno
- ✅ Navegação suave (Smooth Scroll)
- ✅ Animações com CSS
- ✅ Seções organizadas
- ✅ Botões de chamada para ação (CTA)
- ✅ Formulário de contato
- ✅ Validação com JavaScript
- ✅ Código organizado e reutilizável

# 🚀 Como executar

Clone o projeto

```bash
git clone https://github.com/ozzyzk/landing-page-produto.git
```

Entre na pasta

```bash
cd landing-page-produto
```

Abra o arquivo

```
index.html
```

ou utilize o Live Server do VS Code.
